How the AI Thinks

  1. Read revealed numbers
  2. Convert them into logical constraints
  3. Ask Z3 whether each hidden cell must be a mine
  4. Ask Z3 whether each hidden cell must be safe
  5. Mark cells as MINE, SAFE, or UNKNOWN

The agent does not guess. Each cell becomes a true/false variable, each number becomes a constraint ("exactly 1 of these neighbours is a mine"), and Z3 uses logical entailment: to prove C is a mine it assumes C is safe and shows that this contradicts the clues. If no such contradiction appears in either direction, the cell stays UNKNOWN.

Example

Clue = 1

1 A B C

Neighbours: [A] [B] [C]. If A and B are known SAFE, then C must be a MINE.
